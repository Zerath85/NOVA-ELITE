# NOVA ELITE - Yapay Zeka Asistanı 🚀

Python ile yapılmış profesyonel yapay zeka asistanı. Groq API'si ile güçlendirilmiş, harika animasyonlar ve sesli cevaplar.

## ✨ Özellikler

- 🤖 Groq API ile güçlü AI entegrasyonu
- 🎨 Gerçek zamanlı holografik animasyonlar
- 🔊 İki ses sistemi: gTTS (internet) + pyttsx3 (offline)
- 📄 PDF analiz
- 🖼️ Görsel analiz
- 🔗 Web sitesi analizi
- ⚙️ Tam kişiselleştirme ayarları
- 💾 Ayarları otomatik kaydetme
- 📜 Konuşma geçmişi

## 🚀 Hızlı Başlangıç

### Kurulum
```bash
git clone https://github.com/Deskop/Nova-Elite.git
cd Nova-Elite
pip install -r requirements.txt
```

### Çalıştırma
```bash
python Demo.py
```

## ⚙️ Konfigürasyon

1. `.env` dosyası oluştur
2. Groq API anahtarını ekle:
```
GROQ_API_KEY=your_api_key_here
```

3. Uygulamayı çalıştır!

## 📖 Kullanım

- **Komut yazma**: Alttaki input alanına yazıp Enter'e bas
- **PDF analiz**: "pdf analiz et" yazıp PDF dosyası yükle
- **Görsel analiz**: "görsel analiz et" yazıp resim yükle
- **Link analiz**: "link analiz et" yazıp URL yapıştır
- **Ayarlar**: Sol taraftaki ⚙️ butonuna tıkla

## 🛠️ Teknolojiler

- **Framework**: CustomTkinter (UI)
- **AI**: Groq API (llama-3.3-70b)
- **Ses**: gTTS + pyttsx3
- **Kütüphaneler**: pygame, pillow, beautifulsoup4, PyPDF2
